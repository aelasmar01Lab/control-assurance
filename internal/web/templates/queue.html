How to review

Entries are files in the repository, not rows edited here. Open the file, change anything that is wrong, then:

make content checks every file and rebuilds this queue and the control guide.

go run ./cmd/cca review sign <file> marks what you reviewed, with the options shown beside each entry.

An entry with a note carries a doubt the agent recorded. It cannot be signed until its reviewer_note is cleared.
