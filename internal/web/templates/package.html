Review package

Everything recorded for one past period, in one archive: the control states as they stood at the end of the period, every collection run, observation and evaluation in it, the findings that were open, their exceptions and notes, the decision log, and the evidence itself. The period must be over. Asking for the same period again gives a package with the same manifest hash.

Dates are in UTC. To check a package, run cca package verify <file.zip>: it recomputes every hash and re-applies each recorded check version to the stored evidence. Each download is recorded in the decision log with the manifest hash.
